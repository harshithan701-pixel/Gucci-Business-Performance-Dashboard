Gucci – Business Performance Dashboard

Project Overview

A self-initiated Power BI project focused on analysing Gucci's business performance through revenue trends, regional performance and key performance indicators.

Tools Used

- Microsoft Power BI
- Data Analysis
- Data Visualization

Project Objectives

- Analyse business revenue trends.
- Track key performance indicators (KPIs).
- Evaluate regional and product performance.
- Present business insights through visual dashboards.

Key Deliverables

- Interactive Power BI dashboard.
- Revenue performance analysis.
- KPI visualizations.
- Business performance insights.

Project Outcome

Developed a visual dashboard to analyse business performance and communicate key findings through data-driven insights.
